Содержимое файла task_1.py выглядит следующим образом:

1. Вычисление арифмитического выражение `2 + 3 * 4` в строке 1.

1. Присваивание выражения к переменной `course` в строке 3.

Какие литералы пристутсвуют:
- Числовые `2`, `3`, `4`, `4`, `2`
- Строковые `"Python"`, `f"{course}: {hours} часов"`

Список имен и их назначение:

- course — имя переменной, куда сохраняется название курса.

- hours — имя переменной, куда сохраняется результат математического вычисления

## Задание 2

Код программы:
```py
a = 1000
b = a
c = int("1000")

print("Типы:", type(a), type(b), type(c))
print("Идентификаторы:", id(a), id(b), id(c))
print("a == b:", a == b) # Прогноз: True
print("a is b:", a is b) # Прогноз: False
print("a == c:", a == c) # Прогноз: True
print("a is c:", a is c) # Прогноз: False
print("c is None:", c is None)


first = "python"
second = "py" + "thon"

print(f"{id(first)} {id(second)}")
print(first == second)
print(first is second)
```

### Прогнозы выполнения:
- `a == b` будет `True`, так как b = a
- `a is b` будет `False`, так как это 2 разные переменные в памяти
- `a == с` будет `True`, так как c = 1000 после преобразования
- `a is c` будет `False`, так как это 2 разные переменные в памяти

### Результат
3 из 4 прогнозов оказались верными.

Ошибка была в том, что `a is c` возвращает `True`, а не `False`, так как инструкция `b = a` создает ссылку на тот же объект, на который указывает `a`.

### Схема связей между именами и объектами:
- Имена a, b --> Объект 1(значение = 1000)
- Имя c --> Объект 2(значение = 1000)

### Разница между равенством значений и идентичностью объектов:
Операция сравнения значения (`==`) проверяет, равны ли значения между двумя переменными. Данная операция не проверяет, указывают ли имена переменных на один объект. Операция `is`, наоборот, проверяет, указывают ли имена переменных на один объект.

### Объяснение результата
Дан следующий код:
```py
first = "python"
second = "py" + "thon"

print(first == second)
print(first is second)
```

Результат запуска этой программы будет следующим:

```
True
True
```

Возникает следующий вопрос: почему второй print выводит True, если две переменные должны иметь разные адреса в памяти? Это происходит из-за **интернирования строк** (string interning). Для оптимизации работы с памятью и повышения скорости сравнения CPython автоматически сохраняет короткие строки, похожие на идентификаторы (состоящие из букв, цифр и знаков подчеркивания), в специальном внутреннем кэше. Это и есть интернирование.

### Когда применять ==, а когда is
Применять == нужно, когда ты проверяешь два объекта на равентсво данных. Применять is нужно, когда надо проверить, указывают ли переменные на один и тот же конкретный объект в памяти.

### Контрольные вопросы
Создает ли инструкция b = a копию объекта?

Ответ: нет, данная инструкция создает ссылку на объект, на который ссылается переменная `a`.

Что возвращают type() и id()?

Ответ: type() возвращает **тип данных** переменной, а id() возвращает **адрес в памяти**, к которому ссылается переменная.

---

Почему `None` принято сравнивать с помощью `is`, а числа и строки — с помощью `==`?


Ответ: Числа и строки принято сравнивать через `==`, так как данная операция сравнивает данные двух переменных, а не их адреса в памяти. `None` принято проверять через операцию `is`, так как `None` является одним единственным объектом в памяти, поэтому проще проверить, что переменная указывает на память, где находится объект `None`.

## Задание 3

### Разница между операциями `/` и `//`

Операция `//` делит 2 числа и выводит только **целую часть** полученного результата. Если 2 числа являлись целочисленными (int), то и тип результата будет целочисленным. Операция `/` делит два числа и возвращает результат без округления. Тип результата всегда `float`, даже если 2 числа являются целочисленными и результат является целым.

### Большие числа
Целые числа в python имеют неограниченную разрядности и их нельзя переполнить как в других языках с фиксированной разрядностью (C, C++, Java). Python динамически выделяет память под число, и если число выходит за рамки 64 бит, то число будет работать через **алгоритм больших чисел**.

### Представление чисел с плавающей точкой
Python, как и большинство языков программирования использует стандарт IEEE 754 для представления дробных чисел в двоичной системе счисления. 1 бит числа используется для знака, 11 бит для порядка (экспоненты) числа и 52 бита для мантисы (дробной части). Из-за данного стандарта могут возникать неточности при вычислениях дробных значений (самый известный пример 0.1 + 0.2). Это происходит из-за того, что данное число невозможно точно представить в двоичной системе. Из-за этого приходится округлять число, чтобы оно было максимально приближено к оригиналу. Для безопасного сравнения дробных чисел следует использовать функцию `math.isclose()`, которая не учитывает отклонения, которые могут появиться из-за вышеупомянутой проблемы.

### Преобразование типов
`bool("False")` выдает `True`, потому что строка не является пустой. Преобразование строки в bool выдаст `False`, если строка будет пустой. В остальных случаях преобразование выдаст `True`. С числами работает почти также: 0 преобразуется в `False`, а остальные любые числа в `True`.

### Контрольные вопросы
Почему результат обычного деления двух объектов int имеет тип float?

Ответ: Результат деления двух целых чисел не всегда дает целое число, поэтому обычное деление всгда дает дробное число для упрощения. Если нужно получить в результате целое число, используйте деление с округлением до целого (`//`).

В чем отличие преобразования int("42") от int(42.9)?

Ответ: В первом случае мы преобразуем строку, содержащую только цифры в число, а во втором случае мы получаем целую часть дробного числа `42.9`.

### Ошибка присваивания
Вот код программы:
```py
symbol = "Я"
symbol[0] = "д"
```

Код ошибки в строке 2:
```

```

Причина ошибки:
В Python строки (str) являются неизменяемыми (immutable) типами данных. Вы можете обратиться к любому символу строки по индексу для чтения, но изменять её содержимое «на месте» нельзя.

### Контрольные вопросы
Почему `len(symbol)` и `len(symbol.encode("utf-8"))` могут различаться?

Ответ: Первая функция считает количество символов (логических юникодных кодовых точек), а вторая количество байт, которое эти символы занимают в памяти при кодировании в UTF-8.

---

Что означают границы и шаг в записи text[start:stop:step]?

Ответ: start означает с какого элемента начинается срез (по умолчанию 0). stop означает с какого элемента срез заканчивается (по умолчанию последний элемент). step означает с каким интервалом брать элементы (по умолчанию 1)

---

Почему строка считается неизменяемым объектом, хотя методы вроде .upper() возвращают измененный текст?

Ответ: Когда вы вызываете метод вроде .upper(), язык программирования создает абсолютно новую строку в новом месте памяти и возвращает её вам, оставляя оригинал нетронутым.
